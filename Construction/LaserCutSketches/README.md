# LaserCutSketches

SVG cut files for the flower robot's laser-cut structural panels and rod/bearing helpers. All files are print-ready.

## Material

Designed for 3 mm acrylic sheet.

## Cut conventions

- **Red** strokes -> engrave
- **Black** strokes -> cut
- **Blue** strokes -> deep engrave 

## Files

- `LaserBasePlate.svg`, `LaserTopPlate.svg`, `LaserMidPlate.svg` - main chassis plates.
- `LaserMidPlateShell.svg`, `LaserMidPlateShellBearing.svg` - mid-plate shell and its bearing variant.
- `LaserMidBearingMount-Bottom.svg`, `LaserMidBearingMount-Mid.svg` - mid bearing mount, bottom and mid layers.
- `LaserElectronicsPlate.svg` - mounting plate for the electronics.
- `LaserServoMount.svg` - servo mounting bracket.
- `8mmRodHelper.svg`, `10mmRodHelper.svg`, `18mmRodHelper.svg` - alignment helpers for the corresponding rod diameters.
