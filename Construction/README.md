# Construction

This folder contains the physical build documentation for the flower robot: the bill of materials and the laser-cut part sketches used to fabricate the chassis.

## Purpose

Everything needed to source parts and cut the structural components lives here, separate from the firmware and ROS 2 software in the rest of the repository.

## Contents

- `BOM_Aug_18_2026.xlsx`
  - Bill of materials: every purchased and fabricated part required to build the robot.
- [LaserCutSketches](LaserCutSketches)
  - SVG cut files for every laser-cut panel and bearing/rod helper, ready to send to a laser cutter.

## Notes

For engrave/cut conventions and material specs, see the [LaserCutSketches README](LaserCutSketches/README.md).
